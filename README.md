# Барсик — Android

Установочный файл приложения «Барсик» для Android.

**Скачать последнюю версию:** [Barsik.apk](https://github.com/Feroc1ty/barsik-releases/releases/latest/download/Barsik.apk)

После установки откройте ссылку «Добавить подписку» из личного кабинета на [barsikvpn.com](https://barsikvpn.com) — приложение само добавит подписку.
